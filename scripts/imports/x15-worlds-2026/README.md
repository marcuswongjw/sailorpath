## Scoring and source qualifications

- Senior Men's published half-point scores (including 19.5-point penalties) are intentional. Local SI Addendum 1.1(a), visually reviewed on page 2, halves long-distance race scores. No synthetic integer finishes or 39-point penalties replace the published values.
- Local SI Addendum 1, page 3, excludes one score for 3–6 races. Both senior sheets have no discards; the three junior/youth sheets have exactly one printed exclusion per rider. Official tied ranks remain unchanged.
- **Unresolved recap/award discrepancy:** the official U19/U17 Men scoring table has Leo Zabell third (15 nett), Antoni Lutomski fourth (16 nett). The class prose recap instead names Lutomski third and describes Loire as second in every race, while the scoring table has his discarded fourth in R4. The import uses the structured official scorecard for ranks and race points; the source conflict is recorded in every affected sheet result's evidence and public event/sheet notes. No named world-title or category-award schedule is created from the conflicting prose.
- U17/U19 and U13/U15 are combined scored fleets, not duplicate scorecards for each award age group. Age labels remain in row evidence; no birth year/date of birth is inferred. Senior `M`/`GM` suffixes are master categories, removed from profile names and retained verbatim in source evidence.
- Board numbers are reused across fleets (for example 74); they are not global identity keys. No existing profile matched a unique exact normalized official name, declared alias, existing entry label, or reordered full name. All 107 profiles are new; nationality and gender follow the official scorecard/fleet. Unpublished club and birth information remain unset.

## Repeatability and publication

Each manifest is the reviewed source for its standalone SQL file, generated by `build_sql.py`. One transaction per sheet checks event identity, X-15 class and ranking policy, profile identity, participant count, all race totals/discards, result count and race-score count. Conflicting or extra stored rows cause rollback rather than removal.

Every sheet was previewed with lifecycle `draft` inside a production transaction ending in rollback. See `outputs/x15-worlds-2026/import-report.md` for production application, readback and live visibility checks. Applying these SQL files is a production data operation; committing/deploying the source alone does not import the database rows.

## Live checks and profile integration

All five production tables were checked at their canonical parent-event routes. Public results display all race columns, the official source link and Final status, with a source-conflict note on the event. Country-title extraction was corrected during live QA and all 107 result/profile nationalities were read back successfully. New rider IDs were preserved through that correction.

The accompanying application fix adds X-15 to the existing board-profile discipline selection and preserves board numbers separately from Optimist sails. A hook regression and a rendered-profile integration test cover X-15-only profiles, result visibility and absence of an unrelated national standing.
